# Taller7-Laravel2

Resolución del taller 7.

Qué hice en este taller:

* **Creación del proyecto:** Se creó un proyecto en Laravel llamado `EjemploSeg`.

* **Autenticación:** Se instaló y configuró Laravel Breeze para el registro, inicio de sesión y protección de rutas.

* **Base de datos:** Se crearon las migraciones para las tablas `personas`, `intereses` y la tabla pivote `interes_persona`.

* **Modelos y relaciones:** Se configuraron los modelos `Persona` e `Interes` con una relación muchos a muchos.

* **Controladores:** Se implementaron controladores para gestionar personas, intereses, usuarios y el dashboard.

* **Vistas:** Se crearon vistas para registrar personas, registrar intereses y mostrar usuarios registrados.

* **Dashboard:** Se agregó un panel con el total de personas, intereses y usuarios.

* **Diseño:** Se usó Tailwind CSS junto con una plantilla principal y un menú lateral.

* **Pruebas:** Se verificó el registro de usuarios, creación de intereses, creación de personas y navegación del sistema.
